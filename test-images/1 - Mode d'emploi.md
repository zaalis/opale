# Mode d'emploi des images

Ce coffre sert à tester l'insertion et la mise en page des images dans Opale.

- **Cliquer** sur une image la sélectionne : un cadre, quatre poignées et une barre d'outils apparaissent.
- **Tirer une poignée** change la largeur (les proportions sont gardées).
- **Faire glisser l'image** la déplace dans le texte : un trait indique où elle va tomber.
- La barre d'outils choisit la **position** (dans le texte, à gauche, centrée, à droite) et la **taille** (S, M, L, 1:1).
- **Suppr** retire l'image de la note, **Entrée** ou un **double-clic** montre son Markdown, **Échap** désélectionne.
- **Clic droit** sur une image : mêmes réglages dans un menu. Clic droit dans le texte : « Insérer une image ici… ».
- Déposer une image depuis l'Explorateur Windows la place **à l'endroit du dépôt**, avec la taille définie dans Paramètres → Fichiers et liens.

![[petite.png]]

Tout est écrit dans le Markdown, par exemple `![[photo.png|left|320]]` : la note reste un simple fichier texte, lisible dans Obsidian.
